# Changelog

## 0.2.0

- Added a prominent Local / Cloud API processing switch.
- Added OpenAI image-edit processing with a session-only API key.
- Kept cloud processing independent of local runtimes, CUDA, downloaded models, and LoRA.
- Added automatic model-compatible canvas sizing as the default Minimum size option.
- Preserved source dimensions, mirrored folder paths, filenames, extensions, and PNG alpha masks in cloud output.
- Added cloud batch progress and mode-specific readiness information.
- Improved transparent-image preparation and restoration across varied UI asset dimensions.
